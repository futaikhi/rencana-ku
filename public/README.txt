Panduan Upload Logo Kustom RencanaKu:
=======================================
Anda dapat mengganti logo dan favicon secara manual atau langsung melalui aplikasi:

1. CARA 1 (Melalui File Explorer di folder /public):
   - Simpan logo Anda di folder ini dengan nama: `logo.png` (rekomendasi: PNG transparan, rasio 1:1, 128x128 atau 512x512 px)
   - Simpan favicon browser tab Anda dengan nama: `favicon.ico` (atau `logo.ico`)
   - Browser dan aplikasi akan otomatis memuat file ini.

2. CARA 2 (Melalui Antarmuka Aplikasi / Upload UI):
   - Klik menu pengguna di pojok kanan atas aplikasi -> pilih "Pengaturan Logo / Brand" (atau "Ubah Logo").
   - Tarik & lepas (drag-and-drop) atau pilih file .png / .ico langsung dari komputer Anda.
   - Logo dan favicon tab akan langsung terpasang dan tersimpan secara instan!
